# A/B/C 실행 비교 — 2026-10-02

## 사용법

현재 `http://localhost:8090/`은 Route A로 실행했습니다. USB 연결 후 카메라 연결
새로고침 → 동공 검출 설정 → 검출기 선택 → 눈 영역 확인 → 설정 적용을 누릅니다.
각 경로마다 보정이 초기화되므로 1→9→4를 다시 진행합니다. 실험 경로는 중앙 2×2
영역을 제안합니다. 모든 주시 방향의 동공을 포함하고 머리카락·안경테를 제외하세요.

| 선택 | 구현 | 현재 제한 |
|---|---|---|
| 기존 Orlosky | 기존 파일 그대로 | 전체 영역 탐색·가상 구 모델; 비교용 |
| A / orlosky-stable | Orlosky 후보 + 영역/크기/대비/직전 위치 검사 + 곡선 경계 피팅 + 최종 중심 2D | 의미 판별과 가림 복원이 실험적 |
| B / orlosky-stable-3d | 동일 A 타원을 pye3d에 입력 | 카메라 내부 파라미터 미실측; 모델 준비 필요 |
| C / ritnet | 공식 RITnet 동공·홍채·흰자 분할 + 보이는 곡선에서 타원 추정 | CPU 320×240 추론; 도메인·가림 피팅 실패가 있음 |
| PuReST / pure-st | 설치된 오픈소스 시간적 추적 | ROI overload 버그를 피해 영역 밖 마스킹 후 전체영상 API 사용; 지름 제한은 출력 검사 |

ROI와 지름은 새 경로에서 실제로 검사합니다. 큰 이동은 3프레임의 일관된 관측 후
재획득하므로 정상적인 급격한 안구 운동에서도 잠시 소실될 수 있습니다. 예측/이전
좌표로 보정 표본을 채우지 않습니다. 출력 평활화 추가보다 후보 선택 단계에 적용했습니다.
Optical flow는 아직 추가하지 않았습니다.

## 가림과 타원

비스듬한 동공 원판의 투영은 정상적으로 타원입니다. 원으로 강제하지 않습니다.
닫힌 윤곽에서 곡률을 이용해 눈꺼풀이 만든 직선 구간을 제외하고 남은 곡선에
OpenCV ellipse fit을 적용합니다. 곡선 비율·각도 범위·지지율이 부족하면 거부합니다.
학습된 amodal 경계 복원이 아니며 곡선 모양의 눈꺼풀이나 극심한 가림에는 실패할 수 있습니다.
기존 Orlosky dilation은 남아 있어 크기 편향도 추가 평가해야 합니다.

사각형의 모서리만으로 타원을 만드는 회귀 문제를 검사에 포함했습니다. 가린 원의
합성 검사에서 중심 오차 4 처리 px 미만, 짧은 축이 원래 지름의 90% 이상인지 확인했습니다.
실제 눈의 가림 복원 정확도를 증명하는 검사는 아닙니다.
RITnet 색상은 초록=보이는 동공, 파랑=보이는 홍채, 갈색=보이는 흰자입니다.
색칠된 영역 밖으로 이어지는 타원은 별도 피팅의 추정입니다.
공식 소스·가중치·MIT 라이선스·고정 커밋은 `vendor/ritnet/PROVENANCE.md`에 보존했습니다.

## 실제 USB 영상 760프레임 재생 결과

자료는 `recordings/20261002T030107Z-11ef97b2/camera-01.avi`입니다.
3D에는 녹화 프레임의 capture-return timestamp를 사용했습니다.

| 경로 | 품질 기준 이상 후보 | 연속 유효 쌍 | 32 처리 px 초과 이동 | 중앙 처리 시간 |
|---|---:|---:|---:|---:|
| 기존 Orlosky | 755 | 751 | 18 | 11.69ms |
| A | 743 | 734 | 7 | 3.65ms |
| B | 743 | 734 | 7 | 3.94ms |
| C | 345 | 210 | 3 | 48.67ms |
| PuReST | 720 | 700 | 7 | 0.36ms |

기준은 0.65이며 confidence 의미는 방법별로 다릅니다. 정상 안구 운동도 큰 이동으로
집계되고 오검출 고정도 부드러울 수 있으므로 정확도 순위가 아닙니다. B의 준비 완료는
159/760프레임입니다. 동일 타원이므로 검출 수치는 A와 같으며 3D가 더 정확하다는 근거는 아닙니다.
C는 분할 확신도가 높아도 불안정한 윤곽은 거부하여 연속 표본이 부족합니다.
320×240 추론은 원 논문 평가 크기와 다릅니다.

## 원래 수집 구간의 재회귀

같은 시간 창에 새 관측을 대응시켰습니다. 원본도 검출 품질만 분리하기 위해 최종
타원 중심의 2D 좌표를 사용했습니다. PuRe로 기록한 영상에는 Orlosky 가상 구의
사전 보정이 없으므로 원본 3D 변환을 포함한 화면 정확도와 같은 시험이 아닙니다.

| 경로 | 마지막 점 재시도 1 / 2 / 3의 최대 학습 잔차 |
|---|---|
| 원본 중심 2D | 0.437 / 0.537 / 0.516 |
| A | 0.346 / 0.390 / 0.342 |
| B | 준비된 표본 부족 |
| C | 표본 부족 |
| PuReST | 0.323 / 0.306 / 0.325 |

**어느 경로도 기존 기록에서 0.120 기준을 통과하지 않았습니다.** A는 후보 점프를
줄였지만 화면 보정까지 해결한 상태는 아닙니다. 수집 창의 흔들림 검사와 독립
4점 검증을 완전히 재현한 평가도 아닙니다. 실제 반복 보정은 A와 PuReST를 우선
비교하고, B는 실측 파라미터·모델 준비 후, C는 분할 마스크와 거부 원인을 먼저 확인합니다.

프레임별 결과와 수집 구간별 재회귀는 같은 폴더 `route-comparison.json`,
대표 프레임 비교는 `route-comparison.jpg`입니다. 자료는 Git에서 제외합니다.
