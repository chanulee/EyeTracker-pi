# 이전 실험과 참고 코드

이 폴더는 원본 프로젝트와 기존 학생 데모를 보존합니다. 현재 전시 실행 코드는 [exhibition](../exhibition/), 시작 방법은 [메인 README](../README.md), 전체 구조는 [저장소 안내](../docs/REPOSITORY_KO.md)에 있습니다.

- `ForRaspberrypi`: 이전 HTTP MJPEG 영상 송신기.
- `FrontCameraTracker`: 얼굴 앞 카메라 눈 추적 실험.
- `HeadTracker`: 머리 방향으로 마우스를 움직이는 실험.
- `Webcam3DTracker`: 일반 웹캠 눈·머리·화면 매핑.
- `VREyeTracker`: Unity VR 시각화 및 보정.
- `pupil-detectors`: 원본 동공 검출 데모 세 종류.

이 실험들은 전시와 다른 의존성과 하드코딩된 장치·파일 경로를 가질 수 있습니다. 각 폴더의 안내를 읽고 별도로 실행하세요. 원본 코드와 라이선스는 보존했습니다.
