# Seoul Visual AI · 통합 작품 프론트엔드

설치·실행·장비 설정은 [통합본 안내](../README.md)를 따릅니다. Mac에서는 `../start-mac.sh`가 이 production 서버와 1P 시선 처리 서버·브리지를 함께 실행합니다.

이 폴더는 `JiyuShin/Seoul-Visual-Ai`의 `pi-gaze` 브랜치를 기준으로 하며 기존 작품 화면·모바일 연결·에셋을 포함합니다. 출처 SHA와 연결 변경은 [SOURCES.md](../SOURCES.md)에 있습니다. `npm run dev`로 작품만 실행할 때도 시선 처리 서버와 브리지는 별도로 필요합니다.
